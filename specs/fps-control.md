# genshin-uncap 行为规格

## 目标与接口

使用 Windows x64 EXE 启动指定游戏，从外部定位并周期检查 FPS 变量，目标 FPS 在本次运行期间固定

```text
genshin-uncap.exe --game <游戏 EXE 路径> [--fps <1..120>] [--hidden] [--probe] [-- <游戏参数…>]
genshin-uncap.exe --help
```

- `--game` 必填，`--fps` 默认为 120，范围为 1–120；非法、重复或未知参数及无效路径在启动游戏前报告
- 保留 Unicode 路径及逐项游戏参数，`--` 后参数只传给游戏；工作目录为游戏 EXE 所在目录，继承调用环境
- 只控制本次启动的进程，不连接已有游戏；同一会话已有控制器或发现同名游戏进程时拒绝启动，不跨启动复用 PID、句柄或地址
- `--probe` 完成只读定位与稳定性检查后报告并退出，不请求写入权限、不写游戏内存、不启用 F10，游戏继续运行
- 不提供运行时 FPS 调节、配置文件、托盘、注入线程、DLL、shellcode、驱动、权限提升、反作弊绕过、自动更新或遥测

## 初始化与周期控制

流程为 `解析 → 重复启动检查 → 启动 → 定位与验证 → 控制 ⇄ 暂停 → 退出`，探针在定位与验证后退出

- 初始化等待上限为 60 秒，期间检查游戏是否退出；模块或特征未就绪时有界等待，地址歧义、越界、权限和读写错误停止流程
- 首次写入前只读观察有效值稳定至少 500 ms，将该值保存为本次运行不可变的初始限帧值，不硬编码为 60，也不随游戏设置更新
- 控制期间每 500 ms 检查页面、定位指令和 FPS 值，仅当前值与固定目标不同时写入；前后台、菜单及过场不改变目标
- 所有游戏写入均为 1–120 范围内的完整 4 字节值，检查 API 返回值和实际字节数；无匹配、多候选或不完整可访问范围均不写入
- 暂停期间只处理热键、停止请求和游戏存活，不周期访问 FPS 内存

## F10、输出与退出

- 每 20 ms 检查游戏前台窗口所属 PID 和 F10 当前按键状态，仅响应无修饰键的按下边沿；长按只切换一次，初始化忽略输入，切回游戏后必须先观察到松键
- F10 暂停时重新校验地址、定位指令和当前值，按需写回初始保存值后停止覆盖；恢复时重新校验并恢复固定目标及周期检查
- F10 校验或写入失败时停止控制器并报告错误，不报告切换成功；退出请求优先于热键操作
- EXE 使用 Windows GUI 子系统，默认连接或创建控制台，保留继承的输出重定向
- `--hidden` 不创建控制台，运行信息写入 `%LOCALAPPDATA%\genshin-uncap\` 的独立日志；错误时先停止控制，再显示一次错误提示，已创建日志时附上日志位置
- Ctrl+C、关闭控制台、崩溃或强制结束控制器均停止覆盖，不恢复 FPS 值，也不主动终止游戏；最后写入值可能保留至游戏自行更新
- 游戏与控制器控制台隔离，游戏退出后控制器退出；初始化或运行失败不主动关闭已经启动的游戏，不留下继续写入的执行代码

## 兼容与验收标准

Steam／Proton 使用游戏原有 runner 和 prefix，控制器负责启动游戏；隐藏外层批处理属于本地启动配置，`--hidden` 本身不隐藏父级命令窗口

自动化测试使用纯逻辑和自建 Windows 假目标，真实游戏兼容性按具体构建、runner 和场景分别验证；成功构建、内存写入或日志输出均不代表实际达到目标 FPS

| 类别 | 验收场景 |
| --- | --- |
| 参数与启动 | 默认值、1／120 边界、非法值、重复参数、中文与空格路径、空参数与引号透传、重复控制器及已有游戏拒绝 |
| 定位与初始化 | 扫描末尾、等长、超长、跨块、畸形 PE、缺节、负位移、溢出、多候选、页面保护、部分读写、初始化超时及游戏早退 |
| 周期控制与探针 | 同值不写、异值纠正、每次校验、探针零写入、重启不复用地址、控制器退出后无继续覆盖 |
| 暂停与恢复 | 初始值 30／60／120、暂停后游戏自行改值、恢复固定目标、保存值不变、异常值及定位指令变化时停止、退出优先 |
| 热键 | 前台短按、长按、连续切换、修饰键、后台应用、按住切回及初始化期间输入 |
| 输出与生命周期 | 普通输出、重定向、帮助、隐藏日志、日志失败、错误提示、Ctrl+C、关闭窗口、强制结束及游戏先退出 |
| 实际兼容性 | 按具体环境检查启动、实际帧率、前后台、加载与过场、垂直同步、F10、隐藏入口及退出清理，不推广到未测环境 |

本规格定义预期行为，不保存逐次试验状态，也不承诺任意游戏版本、原生 Windows 或其他 Proton 版本已通过验证
